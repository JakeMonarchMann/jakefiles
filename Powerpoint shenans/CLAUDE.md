# Powerpoint shenans

Snake-flow diagram builder for PowerPoint (`snake_gui.py`, via COM automation).

## Versioning — do this every time you change behavior, no need to ask first

1. **Bump the version** — increment the `vX.Y.Z` suffix in
   `root.title("Snake Diagram Builder  vX.Y.Z")` in `snake_gui.py`.
   Bug fix -> patch, feature -> minor, breaking rework -> major.
2. **Log it** — append an entry to `Powerpoint shenans - Version History.md`
   (newest entry at the bottom; never rewrite older entries):

   ```
   ## vX.Y.Z - Month Dth YYYY H:MM am/pm TZ - Author Name
   - what changed
   - what changed
   ```

Do both in the same edit as the change itself.
